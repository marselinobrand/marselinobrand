### 🧑‍💻 Tentang Saya

Saya **Lino**, mahasiswa **Ilmu Komputer** yang suka membangun aplikasi web yang benar-benar dipakai orang, terutama untuk kebutuhan gereja dan komunitas di sekitar saya.

- 🔭 Sedang mengerjakan **[Sistem Slide Liturgi](https://github.com/marselinobrand/sistem-slide-liturgi)**, web untuk tim multimedia gereja membuat slide ibadah tiap minggu (unduh PPTX & tayang langsung di browser)
- ⛪ Membangun **SIM Data Jemaat**, sistem informasi manajemen data jemaat berbasis web (Node.js + Express + PostgreSQL), bahan Kerja Praktek saya
- 🌱 Sedang belajar **Machine Learning & NLP**, khususnya klasifikasi sentimen dengan IndoBERT dan XLM-RoBERTa
- 🎨 Suka bereksperimen dengan UI bertema **dark sci-fi**: animasi halus, efek HUD, dan font futuristik
- 💬 Tanya saya soal **HTML/CSS/JS, Express, PostgreSQL**
- ⚡ Fun fact: saya pernah membuat simulator HUD Arc Reactor dan generator kartu ID hero holografik, hanya dengan vanilla JS
